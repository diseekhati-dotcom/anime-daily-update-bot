# Anime Daily Update Bot

Daily Hindi/Tamil/Telugu anime release updater.

- Source data: Anime Mirchi
- Output label: DC
- Daily post: 5:00 PM IST
- One combined Telegram message for all matching releases found for that day.

## Render variables
BOT_TOKEN = Telegram BotFather token
CHAT_ID = target group/channel chat id (example: -1001234567890)
TZ = Asia/Kolkata

Do NOT commit your real BOT_TOKEN to GitHub.
